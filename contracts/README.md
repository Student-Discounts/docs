# Контракты взаимодействия сервисов

Раздел содержит описание событий и схем сообщений, которыми обмениваются сервисы проекта.

## События Kafka

- [События Catalog Service](events/catalog/CATALOG-EVENTS.md) — обновления каталога для Search Service и других потребителей.

## Организация

Контракты в `events/` сгруппированы по сервису-издателю. Потребители указываются в описании каждого события. Машиночитаемые схемы размещаются в папке `schemas/` соответствующего издателя.

Для каждого события описываются:
- назначение, издатель и потребители;
- топик и ключ сообщения;
- поля, ограничения и пример сообщения;
- версия контракта и правила совместимости;
- правила обработки, включая повторную доставку.
